# Minecraft Naruto Shinobi Plugin

Naruto Shinobi Addon is a Minecraft Java plugin for Paper servers that lets players choose Naruto-inspired jutsu items with the `/naruto` command. It provides Rasengan, Chidori, Kunai, and Shuriken as named items with custom lore; some items also have enchantments.

## Install

1. Build the project with Maven and Java 21 by running `mvn package`.
2. Copy the generated `target/plugin.jar` file into your Paper server’s `plugins` folder.
3. Start or restart the server.

## Use

1. Join the server as a player.
2. Run `/naruto` or `/naruto menu` to view the available items.
3. Run `/naruto rasengan`, `/naruto chidori`, `/naruto kunai`, or `/naruto shuriken` to receive that item. The `ninja` and `jutsu` command aliases are also available.
4. Use the items as their underlying Minecraft items. The plugin does not implement custom jutsu abilities.
